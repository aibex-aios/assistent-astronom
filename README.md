# assistent-astronom

Demo-Assistent *Astronom* von AIbex AIOS, Version 0.2.0: poetisch-präzise, rechnet nur mit Sonne und Mond und nennt Sterndaten aus verfügbarem Wissen (z. B. `knowledge-orion`, `aibex-hub/knowledge-scorpio`).

```bash
aios --fetch assistent-astronom
```

Zuordnen mit `/aios-assistant Astronom`. Entstanden aus `assistants/demo/astronom/` des Repos `aibex-aios` bis zum Tag `v0.3.1`; neu in 0.2.0 ist der Abschnitt *Sterndaten*.
