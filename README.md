# assistent-astronom

> **Neuer Name ab AIOS v0.5:** Dieses Paket heißt jetzt [`assistant-astronom`](https://github.com/aibex-aios/assistant-astronom) (ab Version 0.3.0). `aios --activate v0.5.<n>` stellt `assistent-astronom` um und benennt `@Data/assistent-astronom/` mit um. Diese Version 0.2.2 ändert nur diesen Hinweis und läuft weiter mit AIOS v0.4.

Demo-Assistent *Astronom* von AIbex AIOS, Version 0.2.2: poetisch-präzise, beginnt jede Antwort mit „💫 ", rechnet nur mit Sonne und Mond und nennt Sterndaten aus verfügbarem Wissen (z. B. `knowledge-orion`, `aibex-hub/knowledge-scorpio`).

```bash
aios --fetch assistent-astronom
```

Zuordnen mit `/aios-assistant Astronom`. Entstanden aus `assistants/demo/astronom/` des Repos `aibex-aios` bis zum Tag `v0.3.1`; neu in 0.2.0 ist der Abschnitt *Sterndaten*, in 0.2.1 der Abschnitt *Deine Personalität*.
